# Sports clips

Self-hosted video clips for the "Top 5 Sports Moments" article at
`/learnings/top-5-sports-moments`. Each is pre-trimmed to the moment
itself and re-encoded (H.264/AAC, capped at 720p, `+faststart`) to keep
file size reasonable — trim/compress any new addition the same way
before committing it, rather than committing a raw broadcast download.
